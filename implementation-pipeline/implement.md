# Шаг 5. Отдельные чаты

Вход при `await-chats`, если в сообщении нет слова «ревью».

Бриф уже лежит в файле класса, в секции «Бриф для чата». Родитель исполнителя не запускать. Slug не спрашивать, не записывать и не подставлять. Поле `model` субагенту реализации не передавать. Боевой код не писать.

Если пользователь прислал slug или слово «делай» — работу в этом чате не начинать. Повторить пути файлов и что бриф вставляется в отдельный чат. Модель выбирается в том чате.

Слово «ревью» — выход на [review.md](review.md). Другие слова статус не меняют.
