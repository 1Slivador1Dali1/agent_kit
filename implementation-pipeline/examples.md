# Пример

Задача в промпте, скилл прикреплён: «В пустом селекте календаря на карточке документа покажи уже существующую кнопку создания, только если есть право».

## Ход 1

Анализ: кнопка создания уже есть на вкладке календаря, в селекте её нет. Вопросы не нужны: право и модалка названы. Общий план — один пункт, класс мелкая, файлы селекта и тест права. `medium.md` и `large.md` нет. «Отфильтровано» пусто. В `.cursor/project.md` вид «веб», поэтому в `small.md` выше брифа есть «Проработка дизайна» по уже существующей системе, без нового стиля. Десктоп, бэкенд и мобилка в этот прогон не входят. Дальше раздел «Бриф для чата».

Стоп: «Откройте чат на нужной модели и вставьте бриф из `small.md`. Когда правки лежат в файлах, напишите „ревью“». Исполнитель не запускается. Кода в этом чате нет.

## Ход 2

Пользователь сделал правки в другом чате и пишет: `ревью`.

Один ревьюер без поля `model` сверяет diff с `small.md` и общим планом, код не меняет. Сдача:

### Что реализовано
- Мелкая: пустой селект открывает прежнюю модалку календаря при праве на управление.

### Как проверить
1. Документ без календарей, пользователь с правом — в селекте есть действие создания.
2. Тот же селект без права — текста достаточно, кнопки нет.

### Ревью
- PASS

## Ход 3а

`подтверждаю` → один коммит, push нет, каталог `.cursor/plans/pipeline/...` удалён.

## Ход 3б

`не подтверждаю: кнопка видна без права`.

Один ревьюер сам вносит правки, снова сверяет план, родитель снова сдаёт. Коммита нет, пока не будет подтверждения.
